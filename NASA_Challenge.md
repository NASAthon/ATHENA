# NASA Challenge

## Challenge Name

Create Health Monitoring Software for Astronauts on Space Missions

---

## Problem Statement

Long-duration missions expose astronauts to:

- Radiation
- Isolation
- Altered gravity
- Confinement
- Cardiovascular risk
- Bone loss

Communication delays with Earth can be significant.

Astronauts require onboard tools to monitor health and make informed decisions autonomously.

---

## Required Monitoring

- Heart Rate
- HRV
- SpO₂
- Temperature
- Respiration Rate
- Blood Pressure
- Sleep Quality
- Activity Level
- Radiation Dose

---

## Required Features

### Personalized Baselines

Calculate rolling 14-day baseline values.

### Trend Monitoring

Detect multi-day health changes.

### Alerting

Provide deterministic decision-support alerts.

### Mission Modes

Support:

- ISS
- Lunar Gateway
- Mars Transit
