# ATHENA

NASA Space Apps Challenge 2026

## Problem

Deep-space astronauts face communication delays of
5-40 minutes from Earth.

Medical decision-making must be autonomous.

## Goal

Build an onboard astronaut health monitoring
and decision support system.

## Users

- Astronauts
- Flight Surgeons
- Mission Control

## Crew

3 simulated astronauts

## Core Features

- Personal baselines
- Trend detection
- Explainable alerts
- Mission modes
- Scenario simulation
- Earth Link
- AI chat

## Tech Stack

Frontend:
Next.js
Tailwind
ShadCN

Backend:
FastAPI
Python

Database:
SQLite

AI:
Isolation Forest
LLM Chat Interface
